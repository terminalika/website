Every release ships prebuilt packages and raw binaries on the
[GitHub releases page](https://github.com/terminalika/terminalika/releases).
Pick whichever fits your system; there is nothing else to configure.

Supported platforms: **Linux**, **macOS** and **Windows**, each in `amd64` and `arm64`.
On Windows you need Windows 10+ and a VT-capable terminal (Windows Terminal).

## package managers

<Tabs syncKey="os">
	<TabItem label="macOS / Linux (Homebrew)">
		```sh
		brew tap terminalika/tap
		brew install --cask terminalika
		```
	</TabItem>
	<TabItem label="Windows (Scoop)">
		```powershell
		scoop bucket add terminalika https://github.com/terminalika/scoop-bucket
		scoop install terminalika
		```
	</TabItem>
	<TabItem label="Go">
		```sh
		# needs Go 1.24+
		go install github.com/terminalika/terminalika@latest
		```
	</TabItem>
</Tabs>

## linux packages

Direct downloads; no third-party repository or AUR needed. These links always
resolve to the latest release.

<Tabs syncKey="distro">
	<TabItem label="Debian / Ubuntu">
		```sh
		wget https://github.com/terminalika/terminalika/releases/latest/download/terminalika_amd64.deb
		sudo apt install ./terminalika_amd64.deb
		```
	</TabItem>
	<TabItem label="Fedora / RHEL / openSUSE">
		```sh
		wget https://github.com/terminalika/terminalika/releases/latest/download/terminalika_amd64.rpm
		sudo dnf install ./terminalika_amd64.rpm
		```
	</TabItem>
	<TabItem label="Arch">
		```sh
		wget https://github.com/terminalika/terminalika/releases/latest/download/terminalika_amd64.pkg.tar.zst
		sudo pacman -U terminalika_amd64.pkg.tar.zst
		```
	</TabItem>
	<TabItem label="Alpine">
		```sh
		wget https://github.com/terminalika/terminalika/releases/latest/download/terminalika_amd64.apk
		sudo apk add --allow-untrusted ./terminalika_amd64.apk
		```
	</TabItem>
</Tabs>

`arm64` variants of every package are attached to each release too — file
names use the plain `amd64`/`arm64` pair for every format, not each distro's
native `x86_64`/`aarch64` spelling. Purely cosmetic: package managers read
the real architecture from the package metadata, not the file name.

## raw binaries

If you would rather not use a package: each release also attaches a `tar.gz`
(Linux, macOS) or `zip` (Windows) containing a single static `terminalika`
binary. Drop it somewhere on your `PATH`.

```sh
wget https://github.com/terminalika/terminalika/releases/latest/download/terminalika_linux_amd64.tar.gz
tar xzf terminalika_linux_amd64.tar.gz
install -m 755 terminalika ~/.local/bin/
```
