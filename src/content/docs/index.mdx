## how it works

<Steps>

1. **The agent works. You play.**

   Start a task in Claude Code, Pi, Aider or Cursor, open `terminalika` in
   the next pane and pick Snake, Tetris, Space Invaders or Pong. They are
   built to be dropped mid-move; that's the point.

2. **It listens for the agent.**

   terminalika tails the agent's own session files - no hooks, no proxy,
   nothing leaves your machine (Cursor and anything else post one line from
   a hook). Two events matter: *finished* and *needs your input*. Either
   one freezes the game with a one-line notice in the agent's colour.

3. **The agent is one pane away.**

   The game is already paused - switch panes, answer, come back whenever.
   The game and your score are where you left them. Not at the terminal? A desktop notification, and a
   small background process that keeps listening after every window is
   closed.

</Steps>

## the science of the small wait

Interruption research has measured "just checking" for twenty years: about
23 minutes to get back to an interrupted task, 10-15 minutes before a
developer edits code again, and a screen attention span now around 47
seconds. terminalika doesn't make the wait shorter; it keeps it from
turning into an interruption. [The studies, and what they actually say →](/research/)

## faq

<div class="tk-faq">
<details>
<summary>Does it slow down or interfere with my agent?</summary>

No. It reads the transcript files the agent already writes to disk. No
proxy, nothing injected, nothing sent anywhere.

</details>
<details>
<summary>Which agents?</summary>

Claude Code, Pi Agent and Aider natively. Cursor CLI - and any tool with a
hook - through `terminalika notify`. See [agents](/agents/).

</details>
<details>
<summary>Do I have to play a game?</summary>

No. Say yes to "keep running in the background" and you have a notification
service; open the window only when you feel like a round of Tetris.

</details>
<details>
<summary>Will it pause for every little thing?</summary>

Two events only: the agent *finished*, or it *needs your input*. Tool calls
and subagent chatter are ignored; the same event within three seconds is
deduplicated.

</details>
<details>
<summary>Where do notifications show up?</summary>

Always in the game. On the desktop, when you choose: only while the window
isn't focused (default), always, only when no window is open, or never.

</details>
<details>
<summary>Can I answer the agent from inside the game?</summary>

Not today - the agent is one pane away. Bringing the question itself into
the overlay is where this is heading.

</details>
<details>
<summary>tmux? zellij? Windows?</summary>

All three. Held keys feel best in a terminal that reports key releases;
[terminals](/terminals/) has the list and the fixes.

</details>
<details>
<summary>Is it free?</summary>

MIT-licensed, one static binary, no account.

</details>
<details>
<summary>Why is the logo lowercase?</summary>

Because it lives in a terminal.

</details>
</div>
