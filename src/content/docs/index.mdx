## what it is

`terminalika` is a single static binary that opens a minimalist menu of built-in games and runs the one you pick, full-screen, in the terminal you already have open. It is written in Go on top of [tcell](https://github.com/gdamore/tcell) and ships as `.deb`, `.rpm`, Arch package, Homebrew cask, Scoop manifest and raw binaries for Linux, macOS and Windows.

The twist: it can **watch your coding agent**. Point it at [Claude Code](/agents/claude/) or [pi](/agents/pi/) and the game pauses itself the moment the agent stops and waits for your input, so you never miss a turn while you are busy losing at Tetris.

## quick start

```sh
# Homebrew (macOS / Linux)
brew tap terminalika/tap && brew install --cask terminalika

# open the menu
terminalika

# or jump straight into a game
terminalika --game=tetris
```

Other platforms and package formats: [install](/install/).
